# Product: Expense & Budget Visualizer

A client-side personal finance tracker that lets users log income and expenses, set budgets per category, and visualize spending through a pie chart.

## Key Features
- Add/edit/delete transactions (income or expense) with categories
- Custom categories with user-defined emoji icon and color
- Per-category budget limits with progress bars
- Monthly overall budget progress bar
- Monthly summary (income, expense, net, top spending category)
- Spending pie chart with legend (Chart.js)
- Transaction sorting (date, amount, category) and date filtering
- Light/dark theme toggle
- Slide-in navigation drawer for section anchors
- All data stored in `localStorage` — no backend, no server

## Target User
Indonesian-speaking users tracking personal daily expenses. UI labels and user-facing strings are in Bahasa Indonesia; code comments and variable names are in English.
